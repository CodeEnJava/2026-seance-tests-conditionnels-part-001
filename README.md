## Présentation

Cette séance a pour objectif de découvrir et de maîtriser les structures conditionnelles en Python.

Les tests conditionnels permettent à un programme de prendre des décisions en fonction des données qu'il traite. Ils constituent un élément essentiel de la programmation et interviennent dans la plupart des applications informatiques.

Au cours de cette séance, vous apprendrez à utiliser :

* les expressions booléennes ;
* les opérateurs de comparaison ;
* l'instruction `if` ;
* les structures `if / else` ;
* les structures `if / elif / else` ;
* les opérateurs logiques `and`, `or` et `not`.

---

## Objectifs pédagogiques

À l'issue de cette séance, vous serez capable de :

* Construire des expressions conditionnelles.
* Évaluer des conditions simples et complexes.
